# Affordable Housing Nonprofit — Circular Process Flow Interactive Graphic

## Reframed premise

The nonprofit operates as a set of nested circular processes. At the center is the **mission**. Around it are concentric rings of activity that radiate outward from internal operations to public-facing delivery. The interactive graphic should make this visible: the public-facing work is the outer layer, but it is powered by the inner rings of back-office, governance, finance, and data infrastructure.

The core message: **the public-facing experience is only as good as the operating system behind it.**

---

## The concentric model

```
                        ┌─────────────────────────────────────┐
                        │  OUTER RING: Public-facing work     │
                        │  • Families, donors, tenants,      │
                        │    contractors, funders, board       │
                        │  • Website, portal, events, email,   │
                        │    classes, closings, inspections    │
                        ├─────────────────────────────────────┤
                        │  MIDDLE RING: Mission operations     │
                        │  • Intake, education, counseling,    │
                        │    underwriting, construction,       │
                        │    property management, fundraising  │
                        ├─────────────────────────────────────┤
                        │  INNER RING: Back-office engine      │
                        │  • Finance, accounting, AP, payroll, │
                        │    HR, compliance, grants, audit,  │
                        │    legal, risk, IT, security       │
                        ├─────────────────────────────────────┤
                        │  CENTER: Mission + shared data       │
                        │  • One contact, one property, one    │
                        │    funding source, one program,    │
                        │    one set of outcomes               │
                        └─────────────────────────────────────┘
```

Each ring is a circular process. The outer ring feeds the middle ring. The middle ring feeds the inner ring. The inner ring reports back to the center, which informs the next cycle of the outer ring.

## The four rings in detail

### Center: Mission & shared data

- One constituent / one contact record
- One property record
- One funding source / program record
- One outcome / impact record
- One identity / security model

This is the hub. Every process in every ring reads from or writes to this hub.

### Inner ring: Back-office engine

This is everything it takes to run the business behind the scenes.

| Function | What it does | Enabling questions |
|---|---|---|
| Finance & accounting | GL, AP, AR, month-end, audit, 990, banking, cash flow | Where is the money? Is it coded correctly? Will we pass audit? |
| Payroll & benefits | Staff and contractor pay, taxes, benefits, PTO, compliance | Are people paid correctly and on time? Are we compliant? |
| HR & people operations | Hiring, onboarding, reviews, training, policies, offboarding | Who works here? Are they trained? Are they authorized? |
| Grants & compliance | Funder deadlines, reporting, compliance flags, drawdowns, audits | What is due to whom and when? Can we prove it? |
| Legal & risk | Contracts, insurance, fair housing, privacy, ethics, claims | Are we protected? Are our contracts sound? |
| IT & security | Identity, devices, email, data, backups, AI governance, support | Is our data safe? Is access controlled? Can we recover? |
| Governance & board | Minutes, policies, resolutions, strategic plan, evaluations | Is the board informed? Are we following our own rules? |

### Middle ring: Mission operations

This is where the nonprofit's core programs live.

| Function | What it does | Connected back-office work |
|---|---|---|
| Outreach & intake | Marketing, website, inquiries, referrals, screening, waitlists | Contact records, source tracking, pipeline reports, funder narratives |
| Homebuyer education & counseling | Classes, 1:1 counseling, e-signatures, certificates | Attendance, 9902 reports, case notes, audit trail |
| Down payment assistance | Applications, income verification, underwriting, closing, liens | Loan files, compliance, disbursement, lien recording, servicing, audit |

| Grants management | Opportunities, applications, awards, compliance, reports | Budget narratives, drawdowns, deadlines, audit files |
| Volunteer management | Recruiting, scheduling, hours, background checks, recognition | In-kind valuation, engagement scoring, compliance, reports |

### Outer ring: Public-facing work

This is what the outside world sees and touches.

| Audience | What they do | Experience they expect |
|---|---|---|
| Prospective homebuyers | Attend class, get counseling, apply for assistance | Easy sign-up, clear next steps, fast response, mobile-friendly |
| Current tenants | Pay rent, request maintenance, recertify income | Self-service portal, quick fixes, transparent status |

| Contractors & vendors | Submit bids, invoices, lien releases, draw requests | Clear process, fast payment, fair process |

| Staff & volunteers | Do their daily work with clients and programs | One place to work, no duplicate entry, clear approvals |
| Community partners | Refer clients, co-host events, share data | Easy collaboration, consent handled, data shared safely |

## The circular process flows

Each ring is not a static layer. It is a cycle that continuously feeds the next ring inward and is informed by the ring inside it.

### Outer ring cycle: Engage → Serve → Transact → Follow up

1. **Engage:** A person or organization finds the nonprofit (website, event, referral, email).
2. **Serve:** They receive a service (class, counseling, home, grant, repair).
3. **Transact:** Money, documents, or commitments change hands (donation, rent, application, invoice, award).
4. **Follow up:** The nonprofit closes the loop (receipt, certificate, lease, lien, report, thank-you).

Every transaction in the outer ring creates work in the middle ring.

### Middle ring cycle: Capture → Process → Decide → Deliver

1. **Capture:** Records, documents, attendance, applications, requests are captured digitally.
2. **Process:** Verification, calculation, workflow, approval, scheduling happen.
3. **Decide:** Eligibility, award, draw, lease, hire, or other decision is made and authorized.
4. **Deliver:** The outcome is delivered (certificate, loan, unit, payment, campaign).

Every delivery in the middle ring creates back-office work in the inner ring.

### Inner ring cycle: Record → Report → Comply → Improve

1. **Record:** The financial, legal, HR, and compliance records are created and linked.
2. **Report:** Board reports, funder reports, tax reports, audits, dashboards are produced.
3. **Comply:** Deadlines are met, controls are tested, flags are resolved, audits pass.
4. **Improve:** Insights from reporting and compliance feed the next cycle of outreach and program design.

The inner ring reports back to the center, which then informs the next outer-ring cycle.

## Visual concepts for the circular flow

### Concept A: Living concentric rings

An animated SVG with four concentric rings. Each ring is a circular band of labeled nodes. The center is a glowing hub labeled "One Mission, One Record."

- **Outer ring nodes:** Public-facing touchpoints (Apply, Attend, Donate, Rent, Bid, Report, Volunteer, Refer).
- **Middle ring nodes:** Mission operations (Intake, Education, DPA, Construction, Property, Fundraising, Grants, Volunteers).
- **Inner ring nodes:** Back-office engine (Finance, Payroll, HR, Compliance, Legal, IT, Governance, Audit).
- **Center:** Shared data hub (Contact, Property, Funding, Program, Outcome).

**Interaction:**
- Hover a node → the ring segment expands and shows 3–5 activities.
- Click a node → a side panel shows the process flow and the modules involved.
- Click a ring label → the entire ring rotates slightly and highlights all its nodes.
- Toggle arrows showing data flow direction: outer → middle → inner → center → outer.

**Animation:**
- Subtle continuous rotation of the rings to suggest a living system.
- Pulsing dots along the connecting lines to show records moving inward and insights moving outward.

### Concept B: "Follow one transaction" radial animation

Start at the center with a single record (e.g., Maria's contact). Animate a transaction outward through the rings, then show how it generates work in every ring.

Example: Maria signs up for a homebuyer education class.

- Outer: Maria registers on the portal.
- Middle: HBE module captures registration, schedules her, sends reminders, records attendance, issues certificate.
- Inner: 9902 report line is generated; finance sees the class cost allocation; HR sees counselor hours; compliance sees certificate audit trail.
- Center: Maria's contact record is updated with certificate, attendance, and next-step eligibility.
- Back to outer: Maria is prompted to apply for DPA because her certificate is now linked.

**Interaction:**
- A "Choose a transaction" dropdown at the top: class sign-up, DPA application, rent payment, donation, vendor invoice, grant report.
- The animation plays for the selected transaction.
- Pause and step controls let the user inspect each ring's work.

### Concept C: Radial "day in the life" by role

A circular selector around the outside: Executive Director, Finance Director, Housing Counselor, Property Manager, Development Director, Compliance Manager, IT Director, Board Member. Selecting a role rotates the diagram to show that person's view of the rings.

- **Executive Director:** Mostly inner ring and center, with strategic KPIs.
- **Housing Counselor:** Mostly middle ring, with quick access to outer-ring client interactions.
- **Property Manager:** Middle ring + outer ring tenant portal, with inner-ring AP and compliance.
- **Finance Director:** Inner ring + center, with connections to every middle-ring function.
- **Board Member:** Inner ring governance + center outcomes, with summary views of outer and middle rings.

**Interaction:**
- Select a role → the rings rearrange emphasis; the most relevant nodes glow and expand.
- Click a glowing node → see the role's typical tasks and the reports they need.

### Concept D: Circular process flow with phase gates

A radial process diagram showing the four rings as stages in a loop. Each stage has a gate that must be satisfied before the next stage can begin. The gates are the enabling questions from the back-office engine.

- Gate 1: Who is this? (identity, consent, contact record)
- Gate 2: What happened? (capture, record, document)
- Gate 3: Is it approved? (workflow, authorization, signature)
- Gate 4: How do we pay for it? (budget, funding source, cost allocation)
- Gate 5: Is it compliant? (rules, deadlines, reports, audit trail)
- Gate 6: Where is the money? (cash flow, AP, AR, payroll, grants)
- Gate 7: What do we report? (board, funder, auditor, public)
- Gate 8: Are we improving? (outcomes, metrics, feedback, learning)

These gates form the inner ring. The outer rings must pass through them.

### Concept E: Layered onion with public-facing transparency

A 3D-ish layered onion diagram. The outermost peel is labeled "What the public sees." Peeling it back reveals "What makes it possible." Each layer deeper reveals more of the back-office engine. The center is the shared data hub.

- **Peel 1:** Public-facing website, portal, email, events.
- **Peel 2:** Mission operations — programs, workflows, case management.
- **Peel 3:** Back-office engine — finance, HR, compliance, IT, legal.
- **Peel 4:** Shared data and identity — Dataverse, Entra ID, security model, AI.
- **Core:** Mission and impact.

**Interaction:**
- Hover or click a peel to expand it and see its components.
- A "peel back" button animates the layers opening.
- A "rebuild" button closes the layers back to the smooth outer surface, emphasizing that the public experience is seamless because the inner layers are connected.

## Recommended first build: Concept A + Concept B

Create a new `/operating-system/` page with two connected views:

1. **The living concentric rings** (Concept A) — the default view. A circular diagram of the four rings. Hovering any node shows the process activities and the modules involved. Clicking a node opens a side panel with the full process flow.
2. **Follow one transaction** (Concept B) — a dropdown lets the visitor pick a transaction (class sign-up, DPA application, rent payment, donation, vendor invoice, grant report). The rings animate to show the flow for that transaction, with pause/step controls.

This combination gives both the big picture and the concrete proof.

## Copy principles for the circular flow

- **The public-facing layer is the result, not the product.** The product is the operating system underneath.
- **Use inward/outward language.** "A donation enters the outer ring. The inner ring produces the tax receipt, the GL entry, and the thank-you. The center updates the donor record, which powers the next campaign."
- **Show the cascade.** Every outer action creates middle-ring work, which creates inner-ring work, which updates the center, which enables the next outer action.
- **Emphasize the rings are connected.** Not four separate systems — one continuous loop.
- **Name the business outcomes, not the features.** "Compliance-ready" is better than "has audit log."

## Technical implementation notes

- Build as a custom Power Pages web template with inline SVG and vanilla JS.
- Use CSS animations for ring rotation and data-flow pulses.
- Use the same module metadata from `scripts/Build-Site.ps1` so the page stays in sync.
- Make the SVG responsive: the rings scale, but text stays readable.
- Add keyboard controls: Tab through nodes, Enter to open side panel, Space to play/pause transaction animation.
- Deep-linking: `/operating-system/#transaction=dpa` opens the page with the DPA transaction selected.
- No heavy JS animation libraries; keep it lightweight for portal performance.
