Property Management

Real-estate portfolio, units, tenants, rent rolls, and onboarding workflows for nonprofit-owned properties.

What this module does

Track the nonprofit’s real-estate portfolio: properties, units, tenants, leases, rent rolls, employment verification, and document upload. Built as a Power Platform solution (PropertyManagement, currently v1.6.0.x) with model-driven app, workflows, option sets, and security roles — all sourced under src/Entities, src/Workflows, src/AppModules.

Who it’s for

Affordable-housing nonprofits that own, manage, or operate rental units — including community land trusts, lease-purchase programs, and transitional / supportive housing operators.

Targeted layering: PM_Core / PM_DataLayer / PM_Application / PM_UI, with shared boundary tables (mpp_application*, mpp_employment, mpp_documentupload, mpp_tenant) moving into MPP_Shared_* so Property Management, DPA, and HBE all reference the same family records.

Built on

Microsoft Power Platform — Dataverse for the data and security model, model-driven apps for staff, Power Automate for workflows, Power Pages for constituent self-service, and Copilot Studio agents wired through the native Dataverse MCP server so frontier AI models can read and act on the same records the staff are looking at.
